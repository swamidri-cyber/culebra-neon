# Culebra Neón

El clásico juego de la culebra con estética neón, en un solo archivo HTML sin dependencias.

## Cómo jugar

Abre `index.html` en cualquier navegador moderno. No hace falta instalar nada ni usar un servidor.

Come los puntos rosas para crecer. Cada bocado suma un punto y acelera un poco la culebra. La partida termina si chocas contra una pared o contra tu propio cuerpo.

## Controles

| Acción            | Teclado             | Pantalla táctil     |
| ----------------- | ------------------- | ------------------- |
| Empezar / repetir | Espacio             | Tocar               |
| Moverse           | Flechas o W A S D   | Deslizar el dedo    |
| Pausar / seguir   | P                   | —                   |

## Récord

La mejor puntuación se guarda en el `localStorage` del navegador, así que se conserva entre sesiones en el mismo dispositivo.
